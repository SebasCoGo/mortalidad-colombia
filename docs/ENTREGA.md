# Actividad 4. Aplicación web interactiva para el análisis de mortalidad en Colombia

**Integrante:** Sebastian Contreras Gomez

**Aplicación:** https://mortalidad-colombia-dnrc.onrender.com/

**Repositorio:** https://github.com/SebasCoGo/mortalidad-colombia

La aplicación permite explorar las defunciones no fetales de Colombia en 2019 con filtros por departamento, mes y sexo. Incluye las siete visualizaciones solicitadas. En el README del repositorio se encuentran las instrucciones de ejecución y despliegue, las capturas de pantalla y la explicación de los resultados.
